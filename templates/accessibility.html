Accessibility

Accessibility Statement

This application is designed to be usable by everyone. Two built-in accessibility controls are available on every page to improve readability and visual comfort.

Accessibility Features

Optimized Typography & Readability

The application uses a unified, highly legible sans-serif typeface (Inter) engineered for reading clarity on screens. Generous line heights, strong contrast ratios, and bold headings ensure that all generated summaries and documents are effortless to scan and read comfortably.

Responsive font scaling ensures high legibility across mobile devices, tablets, and desktop displays.

Theme & Dark Mode

Click the theme toggle icon in the navigation bar to switch between Light and Dark modes at any time. High-contrast colors reduce eye fatigue during long reading sessions, and your preference is remembered across sessions.

You can also use the keyboard shortcut Alt+T to toggle the theme instantly.

Found an Issue?

If you encounter anything that prevents you from using a feature, that feedback is genuinely welcome. Accessibility is a core requirement of this project, not an afterthought.

This application is a final-year Computer Science project at Gombe State University, Department of Computer Science.
