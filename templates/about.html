About This Project

Document Summarization Using TF-IDF and MMR with Diagram and Code Preservation for Technical PDF Documents, Gombe State University, Department of Computer Science.

Project Overview

This system is an undergraduate final-year Computer Science project that enables anyone, including students, academics, researchers, and professionals, to upload a document of any length and receive back an intelligent, structured summary without requiring any programming knowledge.

The system implements a multi-factor extractive summarization pipeline using TF-IDF sentence scoring combined with Maximal Marginal Relevance (MMR) for diversity-guaranteed sentence selection. Long documents are split into overlapping chunks and each chunk is scored independently, enabling accurate summarization of documents of any length, from a single page to an entire textbook. Before summarization, the system automatically strips repeated page headers, footers, course codes, watermarks, and other non-content decorations to ensure only genuine document body text is processed.

How It Works

1

Upload

Upload a PDF, DOCX, or TXT file (up to 20 MB) via drag-and-drop or file browser. Files are validated immediately and processed securely on the server.

2

Extract & Clean

Text is extracted using PyMuPDF (PDFs), python-docx (DOCX), or standard I/O (TXT). A two-pass algorithm detects and removes repeated headers, footers, page numbers, watermarks, and figure captions before summarization.

3

Chunk & Summarize

Long documents are split into overlapping chunks. Each chunk is scored using TF-IDF, centrality, and content-type analysis, then the most informative sentences are selected using Maximal Marginal Relevance (MMR) to ensure diversity. The result is grouped into a coherent final summary with labelled headings.

4

Deliver & Export

The structured summary is displayed with key highlights, topic keywords, statistics, and reading times. Download as PDF, DOCX, or TXT with full export customization.

Technology Stack

🐍

Python 3

Core programming language for backend logic, text processing, and summarization algorithms.

⚗️

Flask

Lightweight WSGI web framework for the HTTP API and Jinja2 template rendering.

📐

TF-IDF + MMR

Hand-coded TF-IDF sentence scoring with centrality, content-type bonuses, and Maximal Marginal Relevance (MMR) for diversity-guaranteed extractive summarization.

🔤

Transformers (Tokenizer)

The Hugging Face Transformers library provides the BART tokenizer, used solely for accurate token counting during chunk splitting (no model inference is performed).

📄

PyMuPDF

High-performance PDF text and image extraction with positional bounding-box analysis for header/footer detection.

📝

python-docx

Reading and writing Microsoft Word DOCX documents, including table cell extraction.

📊

ReportLab

Professional PDF generation with support for images, tables, headers, footers, and custom styling.

🌐

HTML5 / CSS3 / JavaScript

Standards-compliant frontend with WCAG 2.1 accessibility, dark mode, and responsive design.

Key System Features

  • Unlimited document length via chunk-and-score pipeline
  • Automatic removal of repeated headers, footers & watermarks
  • 4 summary lengths: Short, Medium, Long, Custom %
  • Paragraph and bullet-point output formats
  • Key highlights and TF-IDF topic keywords extraction
  • Figure and diagram extraction from PDFs
  • Code listing preservation (verbatim, not AI-paraphrased)
  • Real-time progress tracking with cancel support
  • Download as PDF, DOCX, or TXT with custom formatting
  • Reading time estimation and word count statistics
  • Session history (last 5 results, reloadable)
  • Dark mode, high contrast, font size adjuster (WCAG 2.1)
