Help & Documentation

How to Use the Summarizer

Everything you need to know about uploading documents, choosing settings, and getting the best results from the AI.

Quick Start Guide

1

Upload Your File

Drag and drop a PDF, DOCX, or TXT file onto the upload area, or click to browse your files.

2

Choose Length & Format

Pick Short, Medium, Long, or a Custom percentage. Choose Paragraph or Bullet output format.

3

Click Summarize

Press the "Summarize Document" button and watch the real-time progress bar. You can cancel at any time.

4

Download or Copy

Read the summary, copy it to clipboard, print it, or download it as a PDF, DOCX, or TXT file.

Frequently Asked Questions

Before clicking Summarize, choose how detailed the output should be:

  • Short: A high-level overview, roughly 25% of the original length. Best for quickly grasping the main idea.
  • Medium: A balanced summary at around 40% of the original. Captures the main message and key supporting details.
  • Long: A thorough, sectioned summary at about 60% of the original. For long documents, this is automatically broken into labelled sections so nothing major is missed.
  • Custom %: Set an exact target length as a percentage of the original word count, anywhere from 10% to 70%.

Yes, for PDF files. The system handles non-text content in two special ways:

  • Figures & Diagrams: Images embedded in the PDF are extracted and shown alongside the summary on screen, and included in every download format. This means textbook diagrams and charts aren't lost.
  • Code Listings: Code blocks (detected by monospace font usage in the PDF) are extracted and shown verbatim, in a code-formatted box. They are never run through the AI summarizer, as paraphrasing code could break its logic or meaning.

DOCX and TXT files do not currently support figure or code extraction.

Speed depends on two main factors:

  • Document length: Short documents (a few pages) summarize in seconds. Long documents like a full textbook chapter are read section by section, so the progress bar shows which section is currently being processed.
  • First run: The very first summarization after starting the server is slightly slower, because the tokenizer used for chunk splitting needs to initialize. Every summarization after that is faster.

The system uses extractive summarization (TF-IDF + MMR), which runs entirely on CPU and does not require a GPU.

Some PDFs are scanned image PDFs rather than text-based PDFs. They look like text but are actually photographs of pages. This system reads text-based PDFs only. A scanned document would need OCR (Optical Character Recognition) software first; tools like Adobe Acrobat, Google Drive, or open-source alternatives like Tesseract can convert scanned PDFs to text.

No. Uploaded files are deleted from the server immediately after summarization finishes. Only the resulting summary is kept temporarily in memory (for up to one hour) so you can download it. Nothing is saved to disk permanently. Nothing is ever shared with a third party or sent to any external AI service, as summarization runs entirely locally on the server.

The maximum upload size is 20 MB per file. This covers the vast majority of academic papers, reports, and technical documents. If your file is larger, try:

  • Splitting it into chapters or sections and summarizing each separately
  • Removing embedded images or graphics to reduce the file size
  • For DOCX files, saving as PDF with compression can reduce size significantly
