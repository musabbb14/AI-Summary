# User Manual

1. Open the app in a browser.
2. Drag a PDF, DOCX, or TXT file onto the upload area, or click it to browse.
3. Click **Summarize document**.
4. Watch the progress bar — for long documents it will show which section
   is currently being read.
5. When it finishes, read the summary on the page, **copy** it, or
   **download** it as a `.txt` file.
6. Click **Summarize another** to start over.

Tips:
- Very long documents (whole textbooks) take longer but work the same way —
  they're just read in more sections.
- Scanned PDFs without real text underneath (i.e. pure images) can't be
  read yet; use an OCR tool first.
