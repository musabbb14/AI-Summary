# User Manual

1. Open the app in a web browser (`http://127.0.0.1:7860`).
2. Drag a PDF, DOCX, or TXT file onto the upload area, or click it to browse (up to 20 MB).
3. Select your desired summary length: **Short** (25%), **Medium** (40%), or **Long** (60%).
4. Click **Summarize Document**.
5. Watch the real-time progress bar. Click **Cancel** if you need to abort.
6. When processing completes, review the extracted metadata, key highlights, topic keywords, diagrams, and structured notes.
7. Use the quick actions to **Copy** to clipboard, **Print**, or **Download** as **PDF**, **Word (.docx)**, or **Plain Text (.txt)**.
8. Click **Summarize Another** to process another document.

Tips:
- Long documents (full textbook chapters) are split into sections and summarized linearly.
- For PDF files, architectural diagrams and monospaced code blocks are automatically preserved.
- Scanned image-only PDFs without an OCR text layer cannot be read directly; please convert with an OCR tool first.
